# Seller Conversation Patterns — Used Excavator Marketplace

Observational analysis of seller dynamics extracted from 18 human sales recordings.

---

## Key Seller Signals & Behaviors

### 1. Availability Status
- **Direct Inventory**: Seller owns or has direct custody of 1 to 2 machines (e.g., 2x Komatsu PC210 in Singrauli).
- **Broker / Network Supply**: Seller acts as intermediary (*"Party ki machine hai... Mai GM ka number deta hoon"*).
- **Sold Out**: Seller informs machine was already sold out or not currently available for sale.

### 2. Asking Price & Negotiation Dynamics
- **Fixed Demand**: Seller states firm asking price (e.g., *"35 Lakhs demand hai, 33 Lakhs me final"*).
- **Vague / Pending Quotation**: Seller defers price until physical inspection or owner consultation (*"List dekh kar batata hoon"*).

### 3. Machine Condition Disclosure
- **Meter Status**: Meter status disclosed (e.g., *"Meter kharab hai, 9000 hours lagbhag hai"*).
- **Application History**: Work history revealed (e.g., riverbed mining, earthwork, road work).
- **Paperwork / Documents**: Availability of invoice, GST bill, NOC, or financing clearance.

### 4. Seller Follow-up Expectations
- Immediate request for buyer/dealer to send WhatsApp prompt so seller can send machine photos and site location.
