# Sales Conversation Patterns — Used Excavator Marketplace

Based on observational analysis across 18 real human sales calls (Om Shyam Earthmovers).

---

## 1. Observed Conversation Flow



### A. Opening Greeting Patterns
- **OBSERVED PATTERN**: Salesperson opens concisely with company name:
  - *"Hello, Om Shyam Earthmovers se baat kar rahi hoon. Koi machine hai kya sale ke liye / inquiry ki thi aapne?"*
  - Warm, polite tone: *"Namaste sir, Om Shyam Earthmovers se..."*
- **INFERENCE**: Quick identification builds instant credibility with heavy machinery buyers/contractors who get multiple calls daily.

### B. Qualification Sequence
- **OBSERVED PATTERN**: Standard order of parameter extraction:
  1. Machine Brand / Make (e.g., Tata, JCB JS, Komatsu, Sany, Hyundai)
  2. Model / Tonnage (e.g., 200, 210, 215, 225, 370)
  3. Manufacturing Year (e.g., 2024, 2021, 2019)
  4. Running Hours (e.g., 5,000 hrs, 9,000 hrs, meter broken)
  5. Machine Location (e.g., Jaipur yard, Singrauli, Bikaner, Karauli, Assam)
  6. Price / Demand (e.g., 22 Lakhs, 33 Lakhs, 35 Lakhs)

### C. Objection & Reassurance Patterns
- **OBSERVED PATTERN**: When buyer expresses concern about machine condition or terrain application (e.g. mountain quarry vs riverbed soil):
  - Reassurance strategy: *"Company me check karoge to genuine machine milegi... Hum soil/riverbed work ki machine late hain."*
  - Business model clarity: *"Commission ka kaam nahi hai, firm direct purchase karti hai aur margin par sell karti hai."*

### D. Closing & Next Action
- **OBSERVED PATTERN**: Over 90% of successful calls conclude with:
  - Immediate request to transfer machine photos, RC/invoice details, and exact GPS yard location over WhatsApp.
  - *"Aap mujhe WhatsApp par hi ka message kardo, mai photo aur details bhejti hoon."*
